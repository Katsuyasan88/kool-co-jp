プライバシーポリシー

ガチャちょう ／ 文書版 1.2 ／ 制定日 2026-08-31 ／ 最終更新日 2026-09-05

株式会社SmartThanks（以下「運営者」）は、アプリ「ガチャちょう」（以下「本サービス」）における利用者情報を、次のとおり取り扱います。

1. 取得・取り扱う情報

本サービスは、機能の提供に必要な範囲で次の情報を取得または取り扱います。

  • Firebase Authenticationが発行する利用者識別子、ならびに任意に連携したAppleまたはGoogleのprovider識別子
  • 任意のアカウント連携時にAppleまたはGoogleから返され、Firebase Authenticationが保持することがあるメールアドレス、表示名およびプロフィール画像URL
  • 利用者が撮影または選択した台紙画像
  • AI解析結果（商品名、価格、メーカー、種類数、アイテム名、切り抜き範囲等）
  • コレクション記録（ガチャ帳名称、所持数、アイテムの取得日時、取得時点の価格、思い出メモの日付・場所・本文）
  • AI解析の利用履歴（実行日時、成否、利用モデル、処理時間、アイテム数、入力・出力等のトークン数）
  • 利用者が入力したタグ文字列と、共通候補辞書への寄与を管理するための利用者識別子との対応
  • サービス運用上の通信・エラー情報（IPアドレス、リクエスト日時、応答状態等、クラウドサービスが自動的に取り扱う情報を含む）

Apple連携では氏名またはメールアドレスを要求するscopeをアプリから指定しません。Google連携等では、提供事業者とFirebase Authenticationの標準動作により、メールアドレス、表示名またはプロフィール画像URLが認証プロフィールとして返り保持される場合があります。これらをアプリ内プロフィールとして表示したり、Cloud Firestoreの利用者データまたは運用ログへ複製したりしません。認証に使用するIDトークン、Appleの短時間有効な認可コードその他の資格情報は処理のため一時的に取り扱い、アプリまたは運用ログへ永続保存しません。

本サービスは、電話番号、住所または正確なGPS位置情報を取得しません。思い出メモの場所欄は、利用者が任意で入力する文字列です。選択した画像や自由入力欄に個人情報が含まれる可能性があるため、送信前に確認してください。

2. 利用目的

運営者は、取得・取り扱う情報を次の目的で利用します。

  • 匿名アカウントの認証、任意のApple / Googleアカウント連携、別端末からの復元、および利用者本人のデータへのアクセス制御
  • 台紙画像のAI解析、切り抜き、コレクション帳の作成・保存・表示
  • 所持数、アイテム取得明細、思い出メモ、ガチャ帳名称その他の利用者操作の同期
  • 利用者が入力したタグ文字列の共通候補辞書への反映と、他の利用者への候補表示
  • 将来、利用者が希望する期間別利用額や使いすぎ防止機能を提供するための基礎集計
  • 1日10回の解析上限、不正利用の防止、セキュリティの確保
  • 解析の成否、利用量、処理時間および推定コストの把握
  • 障害調査、問い合わせ対応、品質・安全性の改善
  • 法令の遵守、権利侵害への対応、本サービスの保護

取得した情報を、広告配信、第三者への販売または公開プロフィールの作成には使用しません。利用者間で共有するのは、前記の全利用者共通候補に採用されたタグ文字列だけです。

3. 外部サービスの利用

本サービスは、機能提供のため次の外部サービスを利用します。各サービスには、必要な範囲の情報だけを送信または保存します。

提供事業者・サービス取り扱う主な情報利用目的
Google Firebase Authentication / Cloud Firestore利用者識別子、連携provider識別子、providerから返る場合があるメールアドレス・表示名・プロフィール画像URL、コレクション記録、タグ文字列と寄与、アイテム取得日時・取得時価格、AI解析の利用履歴認証、アカウント連携・復元、データ保存、同期、タグ候補、利用上限管理
Apple / Googleの認証サービスprovider識別子、IDトークン、Appleの認可コード、返る場合があるメールアドレス・表示名・プロフィール画像URL利用者の認証、アカウント連携・復元、Apple連携済みアカウント削除時のトークン失効
Amazon Web Services（API Gateway / Lambda / S3 / CloudWatch）認証トークン、台紙画像、保存画像、API処理・エラー情報API処理、画像の切り抜き・非公開保存、障害調査
OpenAIAI解析を実行するために利用者が選択した台紙画像商品情報・アイテム名・切り抜き候補の推定

運営者は、これらの事業者を利用するにあたり、契約、アクセス制御その他合理的な方法により情報の適切な取り扱いを図ります。各事業者による取り扱いには、各事業者の規約・プライバシーに関する定めが適用される場合があります。

4. 第三者提供

運営者は、次の場合を除き、利用者情報を第三者へ提供しません。

  • 本ポリシーに記載した利用目的の達成に必要な範囲で、外部サービス提供事業者へ取り扱いを委ねる場合
  • 利用者の同意がある場合
  • 法令に基づく場合
  • 人の生命、身体または財産の保護のために必要で、同意を得ることが困難な場合

5. 保存場所・保存期間

  • 利用者識別子、任意連携したproviderの認証プロフィール、コレクション記録および共通タグ候補はGoogle Firebase、保存確定した画像はAmazon S3へ保存します。
  • 認証に使うIDトークン、Appleの認可コードその他の短時間有効な資格情報は必要な処理中だけ取り扱い、アプリ、Cloud Firestoreまたは運用ログへ永続保存しません。
  • AI解析時の台紙画像は処理のため一時的に運営者のサーバーとOpenAIへ送信されますが、利用者が保存を確定する前にAmazon S3へ永続保存しません。
  • アカウントに紐づくデータは、サービス提供期間中または利用目的に必要な期間保持します。ただし、利用者がデータリセットまたはアカウント削除を実行した場合は、第6項に従います。
  • ガチャ帳を1冊だけ削除した場合、当該ガチャ帳の画像ファイルはサーバー上に残ることがあります。画面からは参照されず、将来の削除処理またはサービス終了時の整理対象とします。
  • 法令上の保存義務、セキュリティ調査または紛争対応のため保持が必要な情報がある場合は、必要な範囲と期間に限って保持することがあります。

6. 利用者による削除

  • 「データリセット」を実行すると、すべてのガチャ帳、所持数、アイテム取得明細、思い出メモ、利用者ごとの保存画像および当該利用者の共通タグ候補への寄与を削除します。利用者識別子、provider連携、AI解析の利用履歴は、認証、利用上限、不正利用防止およびコスト管理のため保持します。
  • 既に別の保存済みアカウントへ連携して戻る操作で、現在側のコレクションデータ削除へ同意した場合は、データリセットと同じ対象を削除します。以前の匿名アカウント識別子、解析管理情報および当日利用回数は、不正利用防止と処理の再実行を安全に収束させるため保持または連携先へ引き継ぐことがあります。
  • 「アカウントを削除」を実行すると、利用者識別子、provider連携、すべてのガチャ帳、所持数、アイテム取得明細、思い出メモ、保存画像、共通タグ候補への寄与、AI解析の管理情報・利用履歴を削除します。Apple連携済みの場合は、削除前に再認証とトークン失効を行います。削除後は復元できません。
  • アプリ削除だけでは、サーバー上のデータは自動的に削除されません。アプリを削除する前に、必要に応じて「アカウントを削除」を実行してください。
  • アプリ内操作ができない場合は、第11項の窓口へお問い合わせください。匿名アカウントのため、本人のアカウントを特定できない場合があります。

7. 安全管理措置

運営者は、利用者情報への不正アクセス、漏えい、滅失または毀損を防止するため、次の措置を含む合理的な安全管理措置を講じます。

  • Firebase匿名認証と認証トークンによる本人確認
  • ユーザーID単位のFirestore・S3アクセス境界
  • S3の公開読み取り禁止と、短時間だけ有効な署名付きURLによる画像表示
  • APIキー等の秘密情報をアプリへ同梱せず、サーバー側で管理
  • 通信の暗号化、権限の限定、利用履歴・エラーの監視

8. 利用者の権利・請求

利用者は、適用される法令に基づき、自己に関する保有個人データの開示、訂正、利用停止または削除等を請求できる場合があります。請求は第11項の窓口で受け付けます。匿名アカウントの特性上、本人確認または対象アカウントの特定ができない場合は、請求に対応できないことがあります。

9. 未成年者の情報

13歳未満の方は本サービスを利用できません。未成年者は、法定代理人の同意を得た上で利用してください。

10. ポリシーの変更

運営者は、法令、本サービスまたは情報の取り扱いを変更した場合、本ポリシーを改定することがあります。重要な変更は、変更内容と効力発生日をアプリ内または公開サイトで案内します。
